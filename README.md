**AgroSync AI** is a full-stack, AI-powered agricultural marketplace and agronomic advisory platform. It connects smallholder farmers directly with verified corporate procurement buyers to eliminate middleman cuts, while delivering real-time mandi rate updates, hyperlocal weather intelligence, and AI-driven harvest price forecasts.

---

## 🚀 Key Features

- **👨‍🌾 Farmer Produce Management:** List, track, and manage crop lots with real-time KPI metrics (Volume, Value, Batch Counts).
- **🌾 Live Mandi Rates Ticker:** Live ticker showing spot prices and percentage changes for key crops (Wheat, Soybean, Mustard, Cotton, Chana, Basmati Rice).
- **🌤️ Krishi Mausam & AI Weather Advisory:** Hyperlocal weather monitoring (Temperature, Humidity, Wind, Rain probability) with actionable 3-day agronomic advisories.
- **🤖 Kisan AI Assistant:** Interactive one-click agricultural assistant answering queries on pest remedies, N-P-K fertilizer ratios, and MSP price trends.
- **🤝 Direct Procurement Channel:** Eliminates intermediaries by allowing transparent price discovery between farmers and corporate mills.
- **🔒 Secure Authentication & Protected Routes:** Role-based access (Farmer / Buyer) with `bcryptjs` hashing, `JWT` token authorization, and route guards.
- **🛡️ Resilient Architecture:** Built-in graceful offline fallback ensuring 100% demo uptime even under intermittent college network connectivity.

## 🛠️ Tech Stack

| Layer | Technologies Used |
|---|---|
| **Frontend** | React 19, Vite, React Router v7, Modern Responsive CSS |
| **Backend** | Node.js, Express.js REST API |
| **Database** | MongoDB Atlas Cloud + Mongoose ORM (with in-memory fallback) |
| **Security** | JSON Web Tokens (JWT), Bcrypt.js Password Hashing |

## 💻 Quick Start Guide

### 1. Clone Repository
```bash
git clone https://github.com/YOUR_USERNAME/agrosync-ai.git
cd agrosync-ai
```

### 2. Backend Setup
```bash
cd backend
npm install
npm start
```
*Backend runs on `http://localhost:5000`*

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on `http://localhost:5173`*
